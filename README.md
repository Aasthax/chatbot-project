# 🤖 Real-Time Chatbot Web Application (React + Vite)

---

## 📌 Project Overview

This project is a **modern real-time chatbot web application** built using **React, Vite, and JavaScript**.

It simulates a real-world conversational interface between a user and an automated chatbot, focusing on smooth UI experience, keyboard-driven interactions, and efficient state management.

The chatbot is capable of performing simple utility tasks such as flipping a coin, rolling a dice, and providing today’s date, demonstrating conversational command handling.



🌐 **Live Deployment:**  
https://aasthax2103.github.io/chatbot-project/


---

## ⭐ Key Features

---

### 💬 Real-Time Chat Interface
- Dynamic message rendering using React state  
- User and Bot message separation UI  
- Latest messages appear near input (chat-style layout)  
- Smooth chat scrolling behavior  

---

### ⌨️ Smart Keyboard Interaction System
- Enter key to send messages  
- Global typing detection (type anywhere → input auto focus)  
- Cursor auto-focus after sending message  
- Controlled input components  

---

### 🤖 Chatbot Functional Capabilities

The chatbot can perform three built-in actions:

#### 🪙 Flip a Coin
Returns:
- Heads  
- Tails  

#### 🎲 Roll a Dice
Returns a random number between:
1-6

#### 📅 Get Today’s Date
Returns the current date dynamically.

---

### 🎨 Modern Chat UI Design
- Responsive layout  
- Left-right aligned chat bubbles  
- Profile avatar based on sender  
- Fixed bottom input bar (real chat app style)

### 🏗 Frontend Architecture

**Component-Based Architecture**

Input Component → Message Component → Messages Container → App State

Includes:
- UI Layer → Chat Rendering Components  
- Logic Layer → Message Processing + Chatbot Integration  
- State Layer → Centralized Chat State  

---

### 💾 State Management
- React State-based Message Storage

- Controlled Input State Handling
